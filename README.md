# PharManager — نظام إدارة الصيدليات

> تجربة أولية لاستخدام الذكاء الاصطناعي لإنشاء Frontend Vue

نظام متكامل لإدارة الصيدليات يشمل نقاط البيع (POS)، المخزون، المشتريات، الفواتير، والمستخدمين — مبني باستخدام Vue 3 + TypeScript.

## المميزات

- **نقطة بيع (POS)** — إضافة منتجات، اختيار العملاء، تحديد الكميات (دفعة/فاتورة)، طباعة الفواتير
- **إدارة المخزون** — تتبع الأدوية، تواريخ انتهاء الصلاحية، الأرصدة الدفترية
- **المشتريات** —  إضافة فواتير شراء   
- **الفواتير** — عرض وعمل وإرجاع فواتير البيع
- **المستخدمون** — أدوار (مدير، صيدلي، كاشير) مع صلاحيات
- **التقارير** — إحصائيات المبيعات والمخزون
- **واجهة عربية** 

## التقنيات

| التقنية | الاستخدام |
|---------|-----------|
| Vue 3 (Composition API) | واجهة المستخدم |
| TypeScript (strict) | أمان الأنواع |
| Pinia | إدارة الحالة |

| Axios | طلبات HTTP |
| SCSS | التنسيق |

| @lucide/vue | الأيقونات |

## التشغيل

```bash
# تثبيت الاعتماديات

# تشغيل بيئة التطوير
npm run dev

npm run dev:mock
```

## هيكل المشروع

```
src/
├── api/           # واجهات API (axios)
├── components/    # مكونات واجهة المستخدم
│   ├── ui/        # مكونات عامة (أزرار، جداول، إلخ)
│   ├── pos/       # مكونات نقطة البيع
│   └── sections/  # أقسام (شريط جانبي، رأس)
├── composables/   # دوال تفاعلية قابلة لإعادة الاستخدام
├── config/        # إعدادات (الصلاحيات، الميزات)
├── data/mock/     # بيانات وهمية API
├── errors/        # مكون حد الأخطاء
├── layouts/       # تخطيطات الصفحات
├── pages/         # الصفحات
├── router/        # التوجيه
├── services/      # خدمات (المنسق، الطباعة)
├── stores/        # مخازن Pinia
├── styles/        # SCSS (متغيرات، خلطات)
└── types/         # أنواع TypeScript
```

## البنية المعمارية

```
api/ → services/ (callbacks) → stores/ → pages
```

- **الصفحات** لا تستورد دوال التعديل المباشرة من `api/` — تستخدم `services/orchestrator.ts`
- **الخدمات** لا تستورد مخازن Pinia مباشرة
- **المخازن** لا تستورد مخازن أخرى
- تدعم المحاكاة الكاملة عبر `main.mock.ts` + `VITE_USE_MOCK`
